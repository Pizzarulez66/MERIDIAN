# FTB Quests content

The questbook is planned but intentionally not represented by placeholder JSON. FTB Quests uses structured SNBT/JSON data whose schema and task IDs should be generated by the installed version's editor and then committed from a real test instance.

Create chapters in this order:

1. Survey and Salvage
2. The Foundry Charter
3. Bulk to Precision
4. The Chemical Works
5. The Power Spine
6. Regional Industry
7. Project MERIDIAN — Commissioning
8. Optional Engineering Challenges

For every chapter, combine:

- item tasks for actual crafted/processed milestone items;
- description cards explaining the relevant IE/Mekanism integration;
- manual self-audit tasks for physical factory, cable, and logistics layouts that the quest engine cannot inspect by itself;
- optional side tasks that reward alternative designs rather than forcing a single factory blueprint.

The full quest specification is in `docs/progression-and-endgame.md`.
